Saving your work

Read this before you leave work in a browser tab. A run in the browser saves the whole machine locally: memory, processes and the files it wrote, plus the terminal. Nothing is sent to a server.

Pick where saves go:

  • Browser, automatic is the default: every minute while the page is visible (or every 5 or 15 minutes, or only on Save now).
  • Backup file downloads a .snowglobe file you can restore later. Backups can hold passwords, tokens and database contents and are not encrypted: keep them private, and restore only files you trust.
  • Folder, automatic saves into a folder you pick, on browsers with showDirectoryPicker() (desktop Chrome and Edge).

A refresh resumes the last completed save, not necessarily your latest changes. Use Save now before leaving important work.

Saves are tied to the exact site build. After an incompatible rebuild, older ones are kept for export rather than restored.

The agent page keeps machines differently: see machines awake and asleep.
