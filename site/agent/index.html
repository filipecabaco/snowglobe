Machines for agents

Linux machines for agents, in this browser tab: Supabase and a React app on it, which you see live in the preview below, rebuilt after every change an agent makes, beside what it changed; and Python, DuckDB and PostgreSQL for work that needs compute. Run a shell command in any of them, copy files from one to another, and open a machine's web server here. A machine starts on its first command; only a few stay awake at once, and the rest sleep with their files saved.

Machines

  • React + Vite

    Build web apps: a React app on Supabase, rebuilt and served on port 4173 as it changes (Vite, Node)

  • Python + Rich

    Run Python: scripts, numpy and pandas for data work.

  • DuckDB

    DuckDB for analytics: SQL over CSV, Parquet and JSON files.

  • PostgreSQL

    PostgreSQL for database work: load CSV files and query them with psql.

A machine's files are saved in this browser when it is suspended. What an awake machine did since then is lost on reload.

      Each machine runs in a Web Worker of its own, in this tab; nothing runs on a server. Supabase runs on two
          CPUs, which needs the page cross-origin isolated: its service worker does that, so the first visit reloads once. A machine left idle for
          5 minutes, or hidden for a minute, is suspended: its state saved in this browser and its memory freed. The
          next command wakes it with its files as they were. Only a suspended machine's state is kept: reloading the
          page loses what an awake one did since its last suspend, and the browser asks first. Start fresh goes back to
          the machine as built. The page needs the network: it doesn't work offline.
      
        
      Browsers with WebMCP get the tools list_runtimes, run_command, job_status,
          cancel_job, write_file, copy_file, open_preview, close_preview and
          set_awake_limit; scripts in the page get window.snowglobeAgent. Every run, copy and
          preview asks the person at this page first, once per page load, and the page refuses to run inside another
          page's frame. A preview is this site's page: what the machine serves runs here as one.
          More in For agents and programs and llms.txt.
